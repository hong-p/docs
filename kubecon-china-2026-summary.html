3분 요약

ONE-LINE READ
전체 세션 수는 비슷했지만, 행사의 중심은 AI와 짧은 키노트로 이동했다.

2025년 홍콩의 117개 스케줄 엔트리와 2026년 상하이의 129개를 비교하면 전체 양은 비슷합니다. 그러나 키노트는 13개에서 24개로 늘고, 정규 브레이크아웃은 53개에서 46개로 줄었습니다. 세 재단이 각자 키노트 지분을 나누면서 5~10분짜리 짧은 슬롯이 많아졌고, 콘텐츠 세션의 79.5%가 AI / ML / LLM 전반을 다룹니다.

확정·공개 실측 또는 공식 스케줄 스폰서 자료 예상치·소속 기반 추정 공식 수치 미발표

콘텐츠 중심

AI가 배경이 아니라 전제

AI / ML / LLM 전반 언급은 50건(47.2%)에서 93건(79.5%)으로 늘었습니다. 에이전트·MCP는 5건(4.7%)에서 39건(33.3%)으로 뛰며 별도 운영 주제가 됐습니다.

포지셔닝

OpenStack은 AI를 떠받치는 인프라로

OpenStack / OpenInfra 키워드 세션은 2025년 0건에서 2026년 17건으로 나타났습니다. 직접 관련 세션들은 OpenStack 자체 운영보다 AI 에이전트·AI 인프라와의 결합을 전면에 둡니다.

01

올해 행사의 가장 큰 구조 변화

2026년 상하이 행사는 기존 KubeCon 중심의 코로케이션을 넘어, 클라우드 네이티브·오픈 인프라·AI 프레임워크 재단이 한 프로그램 안에서 지분을 나눠 갖는 형태가 됐습니다.

2025년까지

KubeCon + Open Source Summit + AI_dev

2025년 비교군은 홍콩에서 열린 KubeCon + CloudNativeCon + Open Source Summit + AI_dev China 조합입니다. OpenStack / OpenInfra 세션은 0개였습니다.

2026년 상하이

KubeCon + OpenInfra + PyTorch

CNCF(KubeCon), OpenInfra Foundation(OpenInfra Summit), PyTorch Foundation(PyTorch Conference)이 사상 처음 한 자리에서 합쳐졌고, OpenStack 계열 세션이 실제로 들어왔습니다.

읽는 법

행사 이름이 길어진 만큼 단순히 세션 수를 더하는 문제가 아니라, 어떤 재단과 커뮤니티가 프로그램의 중심 의제를 만들었는지를 보는 것이 핵심입니다.

주제 키워드 비교: 2025 vs 2026

  1. AI가 전제가 됐습니다. 콘텐츠 세션 10개 중 8개가 AI를 다룹니다. 2025년에는 절반이 안 됐습니다.
  2. 워크로드 올리기에서 에이전트 운영하기로 이동했습니다. agentic/agent/MCP 언급이 5건 → 39건으로 늘었고, 샌드박싱·옵저버빌리티·런타임·멀티테넌트 보안이 별도 세션으로 등장했습니다.

  4. 하드웨어 다양성이 중국 행사의 고유 축이 됐습니다. Ascend, FlagOS, Cambricon, RISC-V, HiFloat8, device-agnostic PyTorch, “Write Once Run Anywhere” 등이 보이며 NVIDIA 독점 가정을 깨는 세션이 27%입니다.
  5. 이전 주력 주제는 뒤로 밀렸습니다. 플랫폼 엔지니어링, WebAssembly, 옵저버빌리티가 약해졌고 WASM은 올해 0건입니다.

한국 관점에서 눈에 띄는 점

참여 밀도

발표자는 3명뿐

한국 소속 연사는 3명(Samsung SDS 2, NHN Cloud 1)입니다. 2025년 한국 참석자 17명(전체 5위)에 비하면 발표 참여는 얇습니다.

저장소와 연결

이미 이어지는 발표 축

이 저장소 소유자가 Grand Ballroom II(메인 룸)에서 Declarative Underlays를 발표했습니다. KubeEdge 엣지 리소스 컨트롤 라이트닝 토크, In-Place PVC Re-Binding, Lightweight Confidential Containers 관련 자료도 저장소에 있습니다.

진입 기회

이기종 가속기와 프로덕션 사례

중국 벤더(Huawei, DaoCloud, Alibaba, Ant)가 프로그램의 중심입니다. 한국 기업이 들어갈 여지는 이기종 가속기 운영 경험과 금융·통신 프로덕션 사례 쪽에 있습니다.

실제 신호

금융권 에이전트 운영

China Merchants Bank가 금융권 에이전트 운영 사례로 세션을 잡았습니다. “AI를 실제 인프라에 올린 경험”을 공개하는 방향이 한국 관점에서도 유효합니다.

08

다음에 하면 좋을 것

이번 프로그램에서 읽힌 채택 패턴과 저장소의 기존 발표 축을 다음 CFP·프로젝트·공유 자료로 연결합니다.

  1. 내년 CFP 대비

    채택 세션의 공통 패턴은 “프로덕션 규모 숫자 + 오픈소스 프로젝트 이름 + AI 워크로드”입니다. 예: 100k-GPU 잡, 8백만 태스크/일, 수십억 문서 스캔. 규모 숫자 없는 제안은 9% 채택률을 뚫기 어렵습니다.

  2. 에이전트 인프라 공백 노리기

    에이전트 샌드박싱(Kata/Zun), 에이전트 옵저버빌리티, 에이전트용 KV 캐시 계층은 올해 처음 등장한 영역이라 아직 표준이 없습니다. 지금 시작하면 내년 메인테이너 트랙 진입을 노릴 수 있습니다.

  3. OpenStack + Cluster API 계속 밀기

    올해 OpenInfra 세션이 0 → 17건으로 열렸고 경쟁자가 적습니다. Declarative Underlays 후속으로 실제 운영 데이터를 붙인 속편이 유리합니다.

  4. 국내 공유 자료화

    저장소에 이미 있는 한국어 해설 페이지(Declarative Underlays, KubeEdge, PVC Rebinding, Confidential Containers, Cinder CBT) 패턴 그대로 이번 행사 요약 페이지를 공유합니다.

  5. 확정 수치 갱신 예약

    CNCF Transparency Report는 보통 행사 4~8주 뒤 공개됩니다. 2025년판은 2025-07 공개됐으므로, 2026년판이 나오면 참석자·국적·CFP 수치를 실측치로 교체합니다.

  6. 놓친 세션 추적

    녹화가 CNCF WeChat과 YouTube 플레이리스트로 올라오면 AI Infra 트랙 9개, AI+ML 트랙 10개를 우선 시청 목록으로 잡습니다.
